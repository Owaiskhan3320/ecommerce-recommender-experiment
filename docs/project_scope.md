# Project Scope

## Business question
Where do e-commerce visitors drop out of the purchase funnel, and is a simple item-to-item recommender promising enough to justify a real product experiment?

## Real-data work
RetailRocket will be used for descriptive product analytics and offline recommender evaluation.

## Simulated work
A small synthetic experiment will demonstrate assignment, sample-ratio checks, intent-to-treat analysis, confidence intervals, and a decision rule.

## Academic boundary
The real clickstream data is observational. It can show patterns and support predictive evaluation, but it cannot establish that recommendations cause higher conversion.

## Final deliverable
A reproducible GitHub project with SQL, Python, notebooks, a concise experiment plan, and an executive summary.
