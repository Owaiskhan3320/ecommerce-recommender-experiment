# E-commerce Product Analytics, Recommendation Evaluation, and Experiment Design

## Goal
Use real e-commerce clickstream data to understand purchase-funnel drop-off, evaluate a simple item-to-item recommendation approach offline, and design an experiment that could test the recommendation in production.

## Main dataset
RetailRocket e-commerce clickstream dataset.

## What this project will demonstrate
- SQL data modelling and data-quality checks
- Product funnel and cohort analysis
- Offline recommender evaluation with a temporal split
- Experiment design and transparent simulation
- Clear communication of findings and limitations

## What this project will not claim
- That a simulated experiment is a real A/B test
- That offline recommendation metrics prove business impact
- That the recommender was deployed in production
- That observational clickstream patterns prove causality
